# Python package

Generated from the `.proto` files using [betterproto](https://github.com/danielgtaylor/python-betterproto), plus
hand-written client wrappers (`armonik.client`) and helpers (`armonik.common`).

## Installation

```bash
pip install armonik
```

## Updating

The Python package is published to PyPI automatically by CI on every release.

```{note}
There is no edge release for the Python package yet. Only stable releases are published to PyPI.
```
