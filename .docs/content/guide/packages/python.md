# Python package

The Python package is generated from the `.proto` files using [betterproto](https://github.com/danielgtaylor/python-betterproto) and provides a gRPC client for ArmoniK.

## Installation

```bash
pip install armonik
```

## Update Python Package

The Python package is automatically updated by the CI/CD pipeline when a new release is published.

```{note}

There is no edge release for the Python package yet. Only stable releases are published to PyPI.
```
