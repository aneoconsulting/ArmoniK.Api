# What it does: AK_H2_COALESCE=N (read once; unset or 1 = the PR-903 behaviour).
#  - prioritize::buffer_pending hands out up to N x max_frame_size per pop (p4's change), so one
#    stream's queued element is up to N frames long; the PR's per-stream in_flight_partial_send is
#    unchanged: a stream has at most one queued element in flight.
#  - Encoder::buffer: an element longer than the max frame size gets a Split: the first sub-frame
#    head goes in the shared buffer (as the PR's chained head does), the heads of sub-frames 1.. are
#    stored in the element; END_STREAM only on the last sub-frame.
#  - Buf for Encoder (chunk, advance, chunks_vectored, remaining): a split element's wire bytes
#    are walked as payload window 0, head 1, window 1, ... inside the same vectored write as the
#    other queued elements (up to the PR's 1024 slices), stopping where the payload's contiguous
#    chunk or the slice array ends; advance keeps the per-element position (head bytes written).
#
